# Slotwise

A PC build planner that covers consumer, workstation and server hardware, with a rules-based compatibility checker. Simple and easy to use, with new parts being added all the time.

- `parts/<category>/<id>.json` – the hand-checked catalog, one file per part (see [CONTRIBUTING.md](CONTRIBUTING.md) to add one); `parts/_presets.json` holds the starter builds
- `src/catalog.js` – loads the part files and merges in the bulk import
- `src/engine.js` – compatibility engine: `evaluate(build, parts)` returns issues (error / warn / info) and stats (power, PCIe slots and lanes, memory, storage)
- `src/app.js`, `src/page.html`, `src/styles.css` – the UI (no framework, no dependencies)
- `src/catalog.imported.json` – ~6,400 consumer parts generated by `node scripts/import-dataset.js` from the
  [PC Part Dataset](https://github.com/docyx/pc-part-dataset) (MIT, July 2025). Specs the dataset lacks
  (PCIe layout, PSU cables, case clearances) are estimated per platform and flagged in the UI; prices are the
  July 2025 listing scaled by current market factors and shown with `~`
- `node build.js` bundles everything into `dist/index.html` plus `dist/parts.json`
- `npm test` validates every part file and runs the engine tests (CI runs the same on every pull request)
- Merges to `main` publish the site to GitHub Pages automatically

## What the engine checks
Curated server/workstation coverage: EPYC 4004/7003/8004/9004/9005, Xeon E-2400, Xeon Scalable 4th/5th gen, Xeon W-2400/3400/3500, Threadripper 1000-9000 and PRO 3000WX-9000WX (DDR4 X399/TRX40/WRX80 included), with matching boards, RDIMMs, coolers, pro and datacenter GPUs, HBAs, NICs, enterprise drives and rack chassis (prices are list estimates).

Socket and chipset/platform support (e.g. Xeon Scalable on a W790 board), CPU count vs sockets and 1P-only parts,
memory generation, UDIMM/RDIMM/LRDIMM, ECC, slots, capacity, channel population, PCIe slot assignment with
lane sharing (x8/x8), chipset slots, bifurcation adapters, OCP 3.0, M.2 / SATA / SAS / U.2 / U.3 / E1.S / E3.S
connectivity through board ports and HBAs, drive bays, power budget with N+1 redundant modules, PSU cables
(EPS, 8-pin, 12V-2x6), PSU form factor, case fit (board, GPU length, cooler height, radiators, low-profile only),
passive cards and heatsinks needing server airflow, and display output (iGPU or BMC).
